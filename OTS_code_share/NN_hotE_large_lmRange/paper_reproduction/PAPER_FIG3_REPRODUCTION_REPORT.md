# OTS 论文 Figure 3 复现报告

## 结论

北京超算 作业 已按论文文字完成 119,000 次全批量 Adam 更新，作业状态为
`COMPLETED (0:0)`，模型、指标、历史与 Figure 3 共 10 个正式产物的远端
SHA-256 全部通过。测试集总体 EVDF R2 为 `0.9782841`，两个固定测试样本的
Figure 3 面板分别达到 R2 `0.9660` 与 `0.9940`。

本次工作完成了数据、网络、训练日程和四面板评估管线的可复现实现，但不能声称
严格复现了论文展示的全部数值质量。两个训练分布外超高斯面板只恢复了中心轮廓，
存在明显幅值低估和非物理旁瓣：`m=3.5` 的 R2 为 `0.8892`，`m=5` 的 R2 为
`0.8033`。独立诊断 作业 证明这不是解析超高斯谱与 Fourier 正向谱的
实现差异造成的，而是当前严格论文日程模型的真实分布外泛化不足。因此保留原始
结果，不用后处理或把超高斯样本加入训练来伪造论文式贴合。

## 超高斯正向模型诊断

作业 将同一 `m=3.5/5` 超高斯分别通过：

1. `phyEqns.ots_superGaussian.OTS_spectrum_sg` 解析路径；
2. 与训练数据相同的 `OTS_spectrum_fft` Fourier 路径。

两种谱的总 relative L2 仅为 `0.00656` 和 `0.00874`。换成 Fourier 谱后，EVDF
relative L2 只从 `0.31233` 变为 `0.31220`、从 `0.41594` 变为 `0.41479`，
没有实质改善。这排除了“超高斯解析谱与训练谱不一致”作为主要原因。
