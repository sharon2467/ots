# SPEC：pilot 改进、论文对照与 review 成因

日期：2026-09-15。用户目标：尽最大可能改进 pilot，使其接近论文对应结果，并解释 review。执行范围是 pilot 和必要的小规模对照，full 不在本轮范围内。

## 1. Requirements

- 保留 2026-09-14 pilot 作为基线，对相同 15 个源行逐一对照，不靠更换行或降低质量阈值提高通过率。
- 从本地 Zhao et al. 2019 原文确认 Fig.1(a/b/c) 的样本、密度、时间和共同 Ti 假设；用户选择的 TH/TC 独立仍是主要拟合，共同 Ti 仅作为论文对照。
- 改进由可验证的优化/输入条件证据支持，不把论文温度作为拟合惩罚项或强制目标，不修改原始数据、提取器或核心物理公式。
- 保存每行归一化 scale、源索引、实际波长范围、密度、完整候选、优化收敛信息、谱与残差；保留负背景。
- 对每一条原 review 给出对照结果、触发数值及原因，区分局部最优、模型背景失配、弱信号、密度假设、温度不可辨识和论文比较条件不一致。

## 2. Design

采用独立普通函数研究脚本 `improve_ots_pilot.py`，复用现有解析双离子正向函数。先做数值等价核验，再运行实验；不改 canonical 流水线、原 pilot 产物或现有物理代码。

### 模型与优化

八个物理/幅度背景参数及边界沿用现有实现。A、B1、B2 在线性模型中可直接做有界线性最小二乘；外层只搜索 Te、TH、TC、uik、uek，减少温度与幅度背景相互补偿导致的局部陷阱。优化变量按 1000 eV、1e7 cm/s 缩放；使用中央有限差分和固定多初值，同时包含原解及由峰位置估计的漂移初值。记录 SSE、nfev、optimality、status，不能仅凭返回 success 认定找到全局解。

均匀波长网格上的 Gaussian 卷积可用截断至 8σ 的一维核，除以相同核对全一数组的卷积，保持原函数边缘行归一化合同。必须与现有稠密卷积和 `_fit_model` 核对误差；只在数值等价通过后用于多初值试算。主结果不平滑实测光谱。

### 受控对照

1. 同行、同波长范围、同 scale、同密度、同边界，比较原三初值与加强搜索。
2. 保留完整光谱展示，另用包含 IAW 双峰和邻近背景的连续波长范围进行对照，检查宽范围的线性背景假设。范围按谱形/论文显示确定并记录，不隐藏范围外残差，不将不同 N 下的 SSE 当作同一量比较。
3. Fig.1a/b/c 使用原文明示密度 3.5e20/4e20/1e21 cm^-3；先核对时刻与谱形对应。保留 FIG 时间，论文时间变换标成图形匹配推断，不能伪装成原始校准。比较独立 TH/TC 与仅用于复现的 TH=TC。
4. 如发现剩余问题，先在本 SPEC 增补具体对照，再实施；不自动增加任意背景自由度、改电离度或扩大参数边界凑出论文参数。

2026-09-15 对照配置补充：相同15行的 IAW 范围先统一固定为 153 的 [262.0,263.9]、163 的 [261.7,263.5]、020 的 [262.4,264.2] nm，覆盖各自谱峰与邻近背景；作为范围敏感性实验，不修改默认全范围。论文 Fig.1 为内嵌光栅图，可按轴刻度提取灰色实测曲线，以谱形及高频噪声纹理与原始行匹配；拟合温度不参与样本选择。保存像素坐标/读数误差和候选行评分，时间及波长平移仅作为图形定位推断。

图像指纹匹配已定位 Fig.1a/b 为 020 原行234/660（FIG 0.4968/2.7972 ns），Fig.1c 为153原行564（FIG 1.6470 ns）；后者需要 `lambda_paper≈lambda_fig+0.162 nm` 才能对齐噪声纹理。论文条件对照显式记录此推断，不覆盖源坐标；c同时运行无平移和+0.162 nm两组，a/b保持源波长（图像定位差异不超过约0.004 nm）。三例连续拟合范围按论文曲线显示端点为[262.6,264.0]、[262.4,264.15]、[262.0,263.8] nm；窗口作用于各自声明的坐标系。原pilot温度/漂移仍以原FIG坐标报告，除非得到独立校准依据。

二维图像配准进一步支持两份2016数据的波长平移约+0.16 nm（153为0.160、163为0.156），020差异约-0.004 nm，在图像读数精度内。为比较论文时序，另对原15行保留密度假设，使用2016统一+0.16 nm对齐，020保持源波长；范围采用153的Fig.1c显示区[262.0,263.8]、163的Fig.5显示区[262.3,264.3]、020的Fig.1b显示区[262.4,264.15] nm。每行运行独立TH/TC及共同Ti对照。此组只表示论文坐标对照，不覆盖按原坐标完成的同15行主结果。图形时间配准约+0.490/+0.629/+1.492 ns，但Fig.1c文字2.2 ns与对应原行+全图配准不完全一致，保留两项证据并报告，不修改原时间标记。

密度消融只使用有明确依据的数值：Fig.1b 共同Ti分别用论文模拟范围3e20/5e20（原文Fig.2）与中心4e20对照；Fig.1c增加原pilot充气假设6e20与原文明示1e21的独立/共同Ti对照。密度不作为可调参数择优，不给其他时刻伪造局部密度。

```text
冻结来源 → 原文/样本核对 → 正向与卷积等价验证
→ 相同15行多初值改进 → 波长范围/密度/共同Ti消融
→ 论文对应样本对照 → 逐行原因、可信范围及审查图
```

### 函数接口与伪代码

`load_inputs(repo: Path) -> dict`
```text
读取基线 manifest/config/JSON/NPZ 和当前输入
核对输入、基线及物理源码哈希；按源行定位15行
返回物理条件、原始行、原候选及论文对照元数据
```

`signal_model(x: ndarray, nonlinear: ndarray, density: float, physics: dict) -> ndarray`
```text
沿用现有单位/几何转换，调用 OTS_spectrum_maxwellian_two_ion
均匀网格上执行8σ Gaussian卷积及边缘归一化
按卷积后峰值归一，返回有限信号形状
```

`solve_linear(signal: ndarray, x: ndarray, y: ndarray) -> tuple`
```text
构造三列 [signal, 1-fraction, fraction]
先求无约束线性解；若越过A/B边界则有界最小二乘
返回 A/B1/B2、拟合谱和残差
```

`fit_multistart(x: ndarray, y: ndarray, density: float, physics: dict, starts: list, shared_ti: bool=False) -> dict`
```text
对显式初值以缩放参数运行有界 least_squares
每次试探调用 signal_model 和 solve_linear
共同Ti对照把同一变量传给TH/TC；主路径保持独立
保存全部候选及收敛指标，按同网格SSE选最优
评估现有质量标记及实际触边参数，返回参数/谱/残差
```

`make_starts(x: ndarray, y: ndarray, previous: list, shared_ti: bool=False) -> list`
```text
包括原有三组温度和基线成功候选；由宽核仅用于识别谱峰估计谱中心漂移
添加固定温度/漂移组合和固定seed覆盖，不平滑拟合输入
所有初值投影到边界内；去除完全重复初值，保存实际初值及候选编号
```

`compare_case(case: dict, settings: dict) -> dict`
```text
按显式源行/连续列选取I；转float64后计算scale与y
仅论文坐标对照允许显式 wavelength_reference_shift_nm，源波长与源索引一并保存
调用加强拟合；必要时执行共享Ti/密度/范围对照
验证scale有效且回乘恢复源行；保留独立的源波长与拟合波长
返回该案例完整结果与基线可比指标
```

`write_comparison(root: Path, cases: list, provenance: dict) -> None`
```text
写逐案JSON和NPZ，保存scale、源索引、实际拟合范围
绘该案例的实验谱、拟合谱及残差
回读JSON/NPZ核对数组、scale、源行号和SSE；记录三个产物哈希
逐案更新manifest时保留已完成案例；只更新状态时也保留已有清单
```

`main(argv: list[str] | None=None) -> int`
```text
读取显式案例配置与新输出目录；拒绝重复/越界案例ID
支持独立--validate数值验证；实验前已有低中高温验证通过记录
保存源码快照、运行环境、输入哈希和配置；顺序执行案例并逐案落盘
失败写failed及异常信息；完成时核对输入未变并写completed及耗时
不触发full
```

只读论文定位、独立回读验证和报告汇总使用线性脚本，不另建框架。`verify_results.py` 对所有案例核对源数组、scale、边界、候选选择，并用原 `_fit_model` 独立重建；`build_review.py` 从已完成产物生成原/新对照、论文对照、温度多解图及逐行原因表，不重新运行非线性优化。完整源谱及排除区域清楚显示，原范围的残差在主对照图中保留；未参与窄范围拟合的点不伪装成已拟合点。

## 4. Acceptance Criteria / Tests

- 原始FIG/导出NPZ/已有pilot不变，15行无遗漏，scale和索引回读正确。
- 快卷积相对误差<1e-10；同物理输入新旧谱 relative L2<1e-5（明确记录已有标量float32中间转换影响）。低中高温合成闭环达到relative L2<1e-5。
- 同行同范围选中结果SSE不高于基线（浮点容差除外），所有候选和失败信息可查。
- 论文Fig.1三个对应案例提供实际数值对照和来源；不能唯一定位原像素时报告定位不确定性及邻近行变化，不称严格复现。
- 8条原review逐一说明原标记、新标记和证据，无法改善的弱信号或物理不可辨识明确保留。
- 图中原数据、拟合区及排除区域清楚可见；不以共用Ti对照取代用户要求的独立TH/TC主结果；未运行full。

## 5. 实施结果（2026-09-15）

完成五组受控实验：同15行/同范围15例、IAW窗口15例、论文样本7例、同15行论文坐标独立/共同Ti共30例、密度4例；共71例/1211候选。1个候选到迭代上限但未被选中，全部选中解收敛。同15行SSE均不高于基线，最大两项下降24.43%和20.99%；自动状态为6 ok/9 review，原8条review保留，新增163行726的温度多解。没有降低阈值或通过逐行挑选窗口提高通过率。

论文三样本共同Ti对照Te/Ti为210.3/83.9、1404.2/884.6、1756.2/3262.0 eV，对应原文209/78、1392/912、1747/3311 eV；Te偏差均小于1%，Ti最大7.53%。主模型仍独立TH/TC；Fig.1c的独立解与另一温度分支仅差1.103% SSE，自动ok不等于唯一。153行305的强窄谱即使在论文坐标下自动ok，仍明确保留人工复核。

原模型与快卷积低/中/高温最大relative L2=3.66e-13，合成闭环最大3.18e-12；全部71个保存谱用原`_fit_model`重建最大relative L2=8.85e-13。scale回乘最大绝对误差1.82e-12；源FIG/PDF/Notes、输入NPZ、原拟合/物理源码及原pilot的22个产物哈希不变。逐案JSON/NPZ、源行列号、时间、边界和候选最优性校验通过。另完成单候选工程闭环、两案例增量manifest保留和失败状态检查；8张汇总图逐一视觉核查，报告38个链接有效。
